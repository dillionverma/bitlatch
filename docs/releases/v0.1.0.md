# Latch 0.1.0 — private password preview

A compact Mac app and inline Chrome/Aside picker for an existing Bitwarden vault.

## Included

- Email or personal API-key sign-in, master-password unlock, vault search, favorites, login details, secure notes, personal login creation/editing, and password generation.
- Inline account picker and keyboard filling; optional automatic filling per website without auto-submit.
- Offline unlock after sync, screen-lock/sleep/idle locking, and expiring copied credentials.
- Apple Silicon Mac app with light/dark appearance and a virtualized vault list.

## Install

1. Install the official Bitwarden CLI (`brew install bitwarden-cli`), if needed.
2. Download and unzip **Latch-0.1.0-macos-arm64.zip**, then move **Latch.app** to Applications.
3. Open Latch and sign in directly in the app.
4. Open **Browser & settings → Connect browser**, then **Show extension folder**.
5. In Chrome or Aside's `chrome://extensions`, enable Developer mode and load that folder unpacked.

The extension is included in the Mac app. The separate extension ZIP is optional. Keep Latch running for filling. If two inline pickers appear, disable the official extension's password suggestions; its passkey features may remain enabled.

This build is locally ad-hoc signed, not Developer ID notarized. It requires a separately installed official CLI; it does not redistribute Bitwarden's CLI bundle.

## Verified

The packaged app and actual Chrome/Aside executables passed disposable-vault workflows: sign-in, create/edit, inline fill, server-validated form submission, per-site automatic fill, incorrect-origin rejection, lock, clipboard clearing, wrong-password rejection, and offline unlock across restart. API-key sign-in also passed.

18 focused tests, strict TypeScript checks, formatting, and production builds pass. The 10,000-item synthetic renderer benchmark measured about 16 ms p95 search response on the test Mac; it excludes server/crypto time. Full evidence and limitations are in [verification](https://github.com/dillionverma/latch/blob/main/docs/verification.md).

## MVP limits

Passkeys, Touch ID, automatic save prompts, TOTP, enterprise/organization support, and full Bitwarden feature parity are not implemented. Default URI matching uses the exact saved host; explicit base-domain rules allow sibling subdomains. Tests used local Vaultwarden and synthetic credentials; production Bitwarden Cloud account compatibility still needs owner-driven testing. This prototype has not had an independent security review.
