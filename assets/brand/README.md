# Bitlatch artwork

Source color: #145CFF. Created with Icon Composer MCP 1.1.0 and Apple ictool 27.0.

- `Latch.icon/`: editable Icon Composer document and its required glyph.
- `source/clasp.svg`: retained foreground vector.
- `source/flat-icon.svg`: browser icon shape.
- `macos/icon-{16,32,64,128,256,512,1024}.png`: required default macOS icon sizes. The native build generates the asset catalog and ICNS used by the app and AutoFill provider.
- `../../apps/extension/public/icon-{16,32,48,128}.png`: browser toolbar icons.
- `../../apps/raycast/assets/icon.png`: required Raycast icon.
